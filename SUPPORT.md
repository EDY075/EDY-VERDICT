# Support

Supported candidate platform: Windows 10 Pro 22H2 x64 build 19045 with Microsoft Edge WebView2 Evergreen Runtime. Future Windows 11/Linux support is architectural, not a current release claim. Windows Defender is optional; SMBIOS is untrusted.

Use the in-app Diagnostics page for local component/provider state. Review reports before sharing and never send databases, target files, API keys or credential-store content. The current package is unsigned, local-only and not supported for public installation. Unavailable providers and policy-blocked engines reduce coverage rather than silently becoming a pass.
